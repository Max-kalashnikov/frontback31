## Практическое занятие 13

Тема: **Service Worker и офлайн-функционал**

Я сделал веб-приложение для заметок. Пользователь может:

- просматривать список заметок;
- добавлять обычные заметки;
- добавлять заметки с напоминанием;
- работать с заметками даже без интернета.

Заметки сохраняются в `localStorage`. Service Worker находится в файле:

```text
pwa-notes/public/sw.js
```

Он кэширует статические ресурсы приложения, поэтому после первого открытия страница может загружаться из кэша.

## Практическое занятие 15

Тема: **App Shell**

Я переделал приложение под архитектуру App Shell. Основной каркас приложения находится в:

```text
pwa-notes/public/index.html
```

Динамические страницы лежат отдельно:

```text
pwa-notes/public/content/home.html
pwa-notes/public/content/about.html
```

В `app.js` реализована загрузка этих страниц через `fetch`. В Service Worker используется две стратегии:

- для статического каркаса - Cache First;
- для страниц из `/content/` - Network First с fallback на кэш.

Также добавлена страница **О приложении**, которая тоже кэшируется и доступна офлайн.

## Практическое занятие 16

Тема: **Socket.IO и push-уведомления**

Я добавил серверную часть в файле:

```text
pwa-notes/server.js
```

Сервер использует:

- `express`;
- `socket.io`;
- `web-push`.

На клиенте подключается Socket.IO:

```html
<script src="/socket.io/socket.io.js"></script>
```

Когда пользователь добавляет новую заметку, клиент отправляет событие:

```js
socket.emit("newTask", { text, timestamp: Date.now() });
```

Другие вкладки получают событие `taskAdded` и показывают всплывающее сообщение.

Также реализованы кнопки:

- **Включить уведомления**;
- **Отключить уведомления**.

Подписка отправляется на сервер через `/subscribe`, а удаление подписки через `/unsubscribe`.

## Практическое занятие 17

Тема: **Напоминания**

Я добавил форму для создания заметки с напоминанием. Пользователь вводит:

- текст напоминания;
- дату и время.

В `localStorage` заметки теперь хранятся как объекты:

```json
{
  "id": 1710000000000,
  "text": "Текст заметки",
  "reminder": 1710000300000
}
```

Если заметка создается с напоминанием, клиент отправляет событие `newReminder` на сервер. Сервер планирует push-уведомление через `setTimeout`.

В Service Worker добавлена обработка `notificationclick`. Если пользователь нажимает кнопку **Отложить на 5 минут**, Service Worker отправляет запрос:

```text
POST /snooze?reminderId=<id>
```

Сервер переносит напоминание на 5 минут.

## Как запустить

Перейти в папку приложения:

```bash
cd pwa-notes
```

Установить зависимости:

```bash
npm install
```

Запустить сервер:

```bash
npm start
```

Открыть приложение:

```text
http://localhost:3001
```
