О приложении

Это учебное PWA-приложение для практических занятий 13-18. Оно сохраняет заметки в localStorage, работает офлайн через Service Worker и поддерживает установку как отдельное приложение через Web App Manifest.

Для обмена событиями между вкладками используется Socket.IO. Также добавлены push-уведомления и напоминания, которые планируются на сервере.
