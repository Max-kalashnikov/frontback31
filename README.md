# Отчет по практическим занятиям 13-18

Дисциплина: **Фронтенд и бэкенд разработка**  
Тема: **доработка интернет-магазина: заметки, напоминания и PWA-функции**

В этой работе я не делал отдельный сайт вместо магазина. Основным приложением остается обычный интернет-магазин из практических 7-12: есть вход, роли, каталог товаров и админка. Для практик 13-18 я добавил в админку отдельный раздел **"Заметки и напоминания"**.

Отдельная папка `pwa-notes` также оставлена в проекте как учебный пример PWA и запускается на `3013`, но основная сдаваемая версия находится в обычном React-сайте:

```text
frontend/src/App.js
frontend/src/App.scss
```

## Как запустить основной сайт

HTTPS-вариант:

```bash
cd backend
npm run cert
npm run start:https
```

```bash
cd frontend
npm run start:https
```

Открыть:

```text
https://localhost:3001
```

Если браузер покажет предупреждение о локальном сертификате, нужно один раз разрешить переход для `localhost`.

Обычный HTTP-вариант:

Бэкенд:

```bash
cd backend
npm start
```

Фронтенд магазина:

```bash
cd frontend
npm start
```

Открыть:

```text
http://localhost:3001
```

Учебный PWA-пример `pwa-notes`, если нужно открыть отдельно:

```bash
cd pwa-notes
npm start
```

Он запускается на другом порту, чтобы не конфликтовать с магазином:

```text
http://localhost:3013
```

Для проверки админки:

```text
admin@shop.ru
admin123
```

## Практическое занятие 13

Тема: **Service Worker и офлайн-функционал**

В рамках практики нужно было сделать приложение для задач/заметок с сохранением данных в `localStorage`.

Я добавил раздел **"Заметки и напоминания"** в админскую часть магазина. Он доступен только администратору. В этом разделе можно:

- просматривать список заметок;
- добавлять новые заметки;
- отмечать заметки выполненными;
- удалять заметки.

Данные сохраняются в `localStorage`, поэтому заметки не пропадают после перезагрузки страницы.

## Практическое занятие 14

Тема: **Web App Manifest**

В проекте уже есть frontend-приложение на React. Для PWA-части используется manifest из публичной папки React-приложения, а также учебный пример manifest в:

```text
pwa-notes/public/manifest.json
```

В manifest указаны:

- название приложения;
- короткое название;
- стартовый URL;
- режим отображения;
- цвета темы;
- иконки.

Таким образом проект можно проверять как обычный сайт, но при этом PWA-настройки тоже присутствуют.

## Практическое занятие 15

Тема: **App Shell**

Основной сайт работает как SPA-приложение: после загрузки React-каркаса страницы переключаются без перезагрузки браузера. Для практики также добавлен учебный пример App Shell в папке:

```text
pwa-notes/public/
```

Там есть:

- `index.html` как каркас приложения;
- `content/home.html`;
- `content/about.html`;
- Service Worker с кэшированием статических ресурсов и динамических страниц.

В основной версии магазина админский раздел заметок встроен прямо в общий интерфейс.

## Практическое занятие 16

Тема: **Socket.IO и push-уведомления**

В учебной PWA-части `pwa-notes` реализован сервер на Express + Socket.IO + web-push. Он показывает, как можно отправлять события между вкладками и работать с push-подписками.

В основном сайте для админки реализованы браузерные уведомления через Notification API. В разделе заметок есть кнопка:

```text
Включить уведомления
```

Если браузер разрешает уведомления, напоминания показываются системным уведомлением. Если разрешение не выдано, сообщение появляется прямо на странице.

## Практическое занятие 17

Тема: **Напоминания**

В админке добавлена форма создания заметки с напоминанием:

- текст заметки;
- дата и время напоминания.

Заметки хранятся в `localStorage` как объекты:

```json
{
  "id": 1710000000000,
  "text": "Проверить товары",
  "reminder": 1710000300000,
  "done": false
}
```

Когда время напоминания наступает, сайт показывает уведомление. Также у заметки с напоминанием есть кнопка:

```text
Отложить на 5 минут
```

Она переносит напоминание на 5 минут вперед.

## Практическое занятие 18

Тема: **Подготовка к контрольной работе N3**

В результате в проекте есть:

- обычный сайт интернет-магазина;
- авторизация и роли из практик 7-12;

- раздел "Заметки и напоминания" внутри админки;

- напоминания по дате и времени;
- кнопка откладывания напоминания;
- браузерные уведомления;
- отдельный учебный PWA-пример `pwa-notes` с Service Worker, manifest, App Shell, Socket.IO и push.

## Вывод

Я доработал проект так, чтобы он оставался обычным сайтом магазина, как в практических 7-12, но при этом в админской части появился отдельный функционал из практик 13-18: заметки, напоминания, localStorage и уведомления.
